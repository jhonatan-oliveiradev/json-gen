# JSON Gen v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a local-first Next.js tool that converts Smiles airfare campaign spreadsheets into validated production-compatible JSON with correct dropdown grouping and Liferay asset resolution.

**Architecture:** The app uses a deterministic pipeline: XLSX parser -> normalized campaign -> grouping engine -> Liferay asset resolver -> validation engine -> export mapper. The browser owns the local file and interaction state; Next.js route handlers proxy the Liferay calls so the UI never depends on CORS or embeds integration details.

**Tech Stack:** Next.js 16, React 19, TypeScript, Tailwind CSS, shadcn/ui primitives, Zod, SheetJS/xlsx, Vitest, Testing Library.

**Spec:** `docs/superpowers/specs/2026-10-07-json-gen-v1-design.md`

## Global Constraints

- Runs locally with `npm install` and `npm run dev`.
- No authentication, database, analytics, or persistent campaign history in v1.
- Spreadsheet conversion is deterministic; no AI-based correction.
- `SOLTA` rows are never grouped together.
- Dropdown groups are keyed by carousel + normalized dropdown identifier.
- Duplicate route variants with different date and/or price are preserved.
- Liferay document URLs are consumed from the API response; suffixes are never synthesized.
- Blocking validation failures disable JSON export.
- Final JSON must preserve the production field names and null/empty-string behavior evidenced by the supplied valid fixture.
- The UI is a single-page operational workspace with restrained premium styling and clear status hierarchy.

## Review Focus

- XLSX files with extra title rows / blank rows before the real header should still discover the table instead of assuming a fixed row number.
- `SOLTA`, `solta`, whitespace variants, and blank dropdown cells must not accidentally collapse multiple offers into one group.
- A dropdown name reused in two carousels must produce two distinct groups.
- Multiple Liferay files matching the same IATA prefix must surface an ambiguity error rather than pick one arbitrarily.
- Excel date cells represented as serial numbers, JS dates, or `DD/MM/YYYY` strings must normalize to the same exported date format.
